# project-guide

A family of agent skills that guides distributed teams through collaborative research, system design and work planning, step by step, from a goal to fully resolved decisions. Domain-specific execution can optionally follow.

See [overview.md](overview.md) for the concept and scope.

Use `work-on-project` to start or resume the lifecycle, including consent-based
alignment of an opened project's layout. Its phase skills are
`start-project`, `raise-issue`, `refine`, and `decide`, each usable directly.
Unresolved issues live in `open-issues.md`.
Accepted decisions live in `decisions/`, and reviewed executable instructions
live in `tasks/`. Task execution is outside the core skills for now.
